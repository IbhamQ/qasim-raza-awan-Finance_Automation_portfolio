The problem

A balanced total can still hide bad records.

The synthetic source and target files contain duplicates, missing references, invalid formats, metadata disagreements and amount differences. Simply comparing their totals would miss which records need action.

The workflow matches on normalized reference and currency, quarantines incomplete keys, and separates one-to-one matches from records requiring investigation. Each result retains its original CSV row numbers.

Controls that matter.

No unsafe matching

Duplicate amounts are not added into an apparent match. Currency changes create separate keys. Missing or invalid amounts remain blank rather than becoming plausible zeros.

No cross-currency totals

The monetary trends page requires USD or EUR to be selected. Comparable totals use one-to-one keys with valid numeric values and supported currencies.

This case is an AI-assisted portfolio demonstration based on practical reconciliation patterns. It uses synthetic data and does not represent a deployed Fabric pipeline or a completed client engagement.
