# Finnovative Precision Studio source

React 18 product illustration using the MIT-licensed Stageshow kit by Benji Taylor. Page reveals use Anime.js. Static content lives in the surrounding company page.

Extract this archive in a build directory. Run npm ci, then npm run build. Copy the two dist files to finnovative/assets in the site. npm run typecheck validates the TypeScript.

The source is adapted from Stageshow hero-demo: retains Stage, Window, Row, Card, Badge and Button primitives, cursor targets and one-pass choreography; replaces the original developer-tool story with a financial exception review, with reporting/payroll variants. No product/company marks from its examples were copied.

Desktop composition and tab/still/replay interactions were inspected in Chrome. Phone layout is a compact 358px scene. Automated Stageshow filming could not launch Chromium in this environment; no rehearsal-gate pass is claimed.
